# Пошаговая инструкция: деплой OrgChart на VPS через Dokploy

## Что получится в итоге

- Приложение OrgChart доступно по адресу `http://IP-АДРЕС:3000`
- (Опционально) С доменом и HTTPS: `https://ваш-домен.ru`
- Автодеплой при `git push` в GitHub
- Веб-панель управления Dokploy

---

## ЧАСТЬ 1. Подготовка GitHub

### Шаг 1.1. Создать публичный репозиторий

1. Откройте https://github.com/new
2. Заполните:
   - **Repository name**: `orgchart` (или любое другое)
   - **Visibility**: Public
3. Нажмите **Create repository**
4. Скопируйте URL репозитория (например `https://github.com/ваш-логин/orgchart.git`)

### Шаг 1.2. Залить код в GitHub

На вашем компьютере (где код проекта):

```bash
cd orgchart

# Добавить удалённый репозиторий (если ещё не добавлен)
git remote add origin https://github.com/ваш-логин/orgchart.git

# Если remote уже есть, обновить URL
# git remote set-url origin https://github.com/ваш-логин/orgchart.git

# Запушить ветку dev-mvp3
git push -u origin dev-mvp3
```

> **Важно!** Файл `.env` НЕ попадёт в репозиторий (он в `.gitignore`).
> API-ключи и пароли безопасно зададим позже через Dokploy.

---

## ЧАСТЬ 2. Арендовать VPS

### Шаг 2.1. Выбрать хостинг

| Провайдер | Сайт | Минимальный тариф |
|-----------|------|-------------------|
| Timeweb Cloud | https://timeweb.cloud | ~500-700 ₽/мес |
| Selectel | https://selectel.ru | ~600-900 ₽/мес |
| REG.RU | https://reg.ru | ~500 ₽/мес |

### Шаг 2.2. Создать сервер

При создании выберите:
- **ОС**: Ubuntu 22.04 LTS (или 24.04)
- **Тариф**: минимум **4 GB RAM**, 2 vCPU, 30+ GB SSD
- **Регион**: Москва / Санкт-Петербург
- **Способ доступа**: пароль (проще для начала)

После создания вы получите:
- **IP-адрес** сервера (например `185.123.45.67`)
- **root-пароль**

Запишите их — понадобятся далее.

---

## ЧАСТЬ 3. Подключиться к серверу

### Шаг 3.1. Подключение по SSH

**На Windows:**
- Откройте PowerShell (или установите PuTTY)

**На Mac/Linux:**
- Откройте Терминал

Введите команду:

```bash
ssh root@185.123.45.67
```

(замените `185.123.45.67` на ваш IP)

- При первом подключении спросит "Are you sure?" — введите `yes`
- Введите root-пароль

Вы увидите приглашение вроде `root@server:~#` — вы на сервере!

## ЧАСТЬ 4. Установить Dokploy

### Шаг 4.1. Установка (одна команда)

```bash
curl -sSL https://dokploy.com/install.sh | sh
```

Установка займёт 3-5 минут. В конце увидите:

```
Dokploy is now running on port 3000
Access it at http://ВАШ_IP:3000
```

### Шаг 4.2. Открыть панель Dokploy

1. Откройте в браузере: `http://ВАШ_IP:3000`
2. Создайте аккаунт администратора Dokploy (это для панели управления, не для OrgChart)
3. Запомните логин/пароль

> **Примечание**: Dokploy по умолчанию занимает порт 3000. Наше приложение
> будет доступно через другой порт или через домен (настроим далее).

---

## ЧАСТЬ 5. Создать проект в Dokploy

### Шаг 5.1. Создать проект

1. В панели Dokploy нажмите **Projects** → **Create Project**
2. Название: `orgchart`
3. Нажмите **Create**

### Шаг 5.2. Создать Compose-сервис

1. Внутри проекта нажмите **+ Create Service** → **Compose**
2. Настройки:
   - **Name**: `orgchart`
   - **Source**: **GitHub**

### Шаг 5.3. Подключить GitHub-репозиторий

1. **Provider**: выберите GitHub
2. Если GitHub ещё не подключён:
   - Нажмите **Configure Git Provider**
   - Выберите **GitHub App** → следуйте инструкциям (авторизация через GitHub)
3. Выберите ваш репозиторий: `ваш-логин/orgchart`
4. **Branch**: `dev-mvp3`
5. **Compose Path**: `./docker-compose.prod.yml`

### Шаг 5.4. Настроить переменные окружения

Перейдите во вкладку **Environment** и добавьте:

```env
DB_PASSWORD=придумайте_сложный_пароль_для_БД
NEXTAUTH_SECRET=вставьте_сгенерированный_ключ
NEXTAUTH_URL=http://ВАШ_IP:3000
```

**Как сгенерировать NEXTAUTH_SECRET:**

На сервере (через SSH) выполните:
```bash
openssl rand -base64 32
```
Скопируйте результат и вставьте как значение `NEXTAUTH_SECRET`.

**(Опционально)** Если хотите AI-ассистент:
```env
ANTHROPIC_API_KEY=sk-ant-ваш-ключ
VOYAGE_API_KEY=ваш-ключ
```

### Шаг 5.5. Настроить домен (выберите вариант)

#### Вариант А: Без домена (по IP-адресу)

Перейдите во вкладку **Domains** и добавьте:
- **Host**: `ВАШ_IP`
- **Port**: `3000`
- **HTTPS**: выключено

Приложение будет доступно по `http://ВАШ_IP:порт`

> Порт может отличаться от 3000, т.к. Dokploy сам занимает 3000.
> Dokploy назначит свободный порт — он будет показан после деплоя.

#### Вариант Б: С доменом и HTTPS (рекомендуется)

Если у вас есть домен:

1. В DNS-настройках домена добавьте **A-запись**:
   - **Имя**: `@` (или `orgchart`)
   - **Значение**: `ВАШ_IP`
   - **TTL**: 300
2. Подождите 5-10 минут (DNS-распространение)
3. В Dokploy → **Domains**:
   - **Host**: `ваш-домен.ru`
   - **Port**: `3000`
   - **HTTPS**: включено
   - **Certificate**: Let's Encrypt

Переменную `NEXTAUTH_URL` обновите на: `https://ваш-домен.ru`

### Шаг 5.6. Запустить деплой

1. Нажмите кнопку **Deploy**
2. Следите за логами в реальном времени
3. Первый деплой займёт 3-7 минут (сборка Docker-образа)
4. Когда увидите `Ready` — приложение запущено

## ЧАСТЬ 6. Первоначальная настройка приложения

### Шаг 6.1. Применить seed (создать администратора)

В Dokploy перейдите в ваш Compose-сервис → вкладка **Advanced** → **Terminal** (или через SSH на сервере):

```bash
# Найти ID контейнера приложения
docker ps | grep orgchart

# Запустить seed
docker exec -it ИМЯ_КОНТЕЙНЕРА_APP npx prisma db seed
```

Или через Dokploy UI: откройте **Terminal** контейнера `app` и выполните:
```bash
npx prisma db seed
```

### Шаг 6.2. Войти в приложение

Откройте в браузере ваш адрес и войдите:

- **Email**: `admin@orgchart.local`
- **Пароль**: `admin123`

### Шаг 6.3. Сменить пароль и создать пользователей

1. Войдите как `admin@orgchart.local`
2. В левом меню внизу нажмите **Пользователи**
3. Отредактируйте пароль администратора (замените `admin123`!)
4. Создайте аккаунты для остальных пользователей

---

## ЧАСТЬ 7. Настроить автодеплой

### Шаг 7.1. Включить автодеплой

В Dokploy → ваш Compose-сервис → вкладка **General**:

1. Включите тогл **Auto Deploy**
2. Dokploy покажет **Webhook URL**

Теперь каждый `git push` в ветку `dev-mvp3` будет автоматически запускать пересборку.

### Шаг 7.2. Как обновлять приложение

На вашем компьютере:

```bash
# Внесите изменения в код
git add .
git commit -m "описание изменений"
git push origin dev-mvp3
```

Dokploy автоматически:
1. Скачает новый код
2. Соберёт Docker-образ
3. Перезапустит контейнеры
4. Применит миграции Prisma

## Решение проблем

### Приложение не запускается

```bash
# Посмотреть логи в Dokploy
# Перейдите в Compose → вкладка Deployments → кликните на последний деплой
# Или через SSH:
docker logs ИМЯ_КОНТЕЙНЕРА_APP --tail 50
```

### БД не подключается

Проверьте что `DB_PASSWORD` в Environment совпадает в обоих местах (POSTGRES_PASSWORD и DATABASE_URL).

### "Неверный email или пароль"

Seed не был выполнен. Запустите:
```bash
docker exec -it ИМЯ_КОНТЕЙНЕРА_APP npx prisma db seed
```

### Миграции не применились

```bash
docker exec -it ИМЯ_КОНТЕЙНЕРА_APP npx prisma migrate deploy
```

### Не хватает памяти

Если сервер зависает:
```bash
# Проверить память
free -h

# Создать swap-файл (если нет)
fallocate -l 2G /swapfile
chmod 600 /swapfile
mkswap /swapfile
swapon /swapfile
echo '/swapfile none swap sw 0 0' >> /etc/fstab
```
