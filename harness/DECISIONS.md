## 2026-08-21 — Производный сценарий называет базу прямо в имени
- Решение: cloneScenario дополняет имя «(из: Родитель)» (обрезка 40 симв,
  без дублей и каскадов); list_scenarios отдаёт createdFrom; для старых
  сценариев связь показывает подстрочник в селекторах — их не переименовываем
- Причина: имя задаёт LLM свободным текстом и связи не несёт, а createdFromId
  в БД уже был — не хватало только отражения в местах, где виден голый name

## 2026-08-21 — Словарь меток инструментов — единый server-safe модуль
- Решение: src/lib/ai/tool-labels.ts — один словарь для чипов UI, пометки
  обрыва и стримового фильтра; имена в дельтах заменяются на сервере с
  удержанием незавершённого слова (имя, разрезанное границей дельт, ловится)
- Причина: три места показывали сырые snake_case-имена из-за неполного
  клиентского словаря; фильтр на сервере покрывает их все одной точкой

## 2026-08-21 — Все лимиты прогона — per-preset, пусто = дефолт из кода
- Решение: maxSteps / stepTimeoutSec / chunkTimeoutSec / runContextBudgetBytes
  добавлены в LlmSetting по цепочке toolResultMaxBytes; константы limits.ts
  остались дефолтами
- Причина: лимиты принадлежат связке модель+шлюз и должны переключаться
  вместе с пресетом; эмпирические величины (бюджет 120 КБ — ~2/3 от
  наблюдавшихся 180 КБ) должны крутиться без редеплоя

## 2026-08-21 — Метаданные прогона — отдельным SSE-событием meta
- Решение: бюджет времени, предел и номер шага сервер шлёт событием meta;
  индикатор показывает «Шаг N из ≤30», таймер шага и «X / бюджет» с
  цветовыми порогами 80/95%
- Причина: клиент не может знать бюджет и шаг сам, а канал status кастуется
  в enum фаз — служебные значения ломали бы отображение фазы

## 2026-08-21 — Тройной таймаут total/step/chunk вместо одного общего
- Решение: streamText с timeout {totalMs: пресет ≤3600 с, stepMs: 10 мин,
  chunkMs: 2 мин}; подрезка под maxDuration только на Vercel; шагов до 30
- Причина: один общий потолок не различал «длинный reasoning» и «мёртвое
  соединение» — первый легален и должен жить, второе надо рубить за минуты.
  Автопродолжение между запросами отложено до переезда в облако

## 2026-08-21 — Из окна редактируется только методическая часть промпта
- Решение: промпт разделён на методическую половину (БД, /admin/settings/prompt,
  плейсхолдер {{scenario_name}}) и техническую (только код, в UI read-only);
  нет строки в AiPromptSetting = дефолт из кода, сброс = удаление строки
- Причина: технические секции (маршрутизация инструментов, усечение) настроены
  под таймауты — их правка из окна молча ломает поведение чата

## 2026-08-20 — Колоночный формат выдачи оргструктуры для LLM
- Решение: get_org_structure отдаёт columns (строка) + rows вместо массива
  объектов; ФИО руководителя заменено флагом hasHead
- Причина: имена ключей занимали ~120 из 333 Б на запись и ехали в модель на
  каждом шаге. 333 → 179 Б; страница на 200 подразделений впервые укладывается
  в потолок 60 000 Б. columns именно строкой: capToolResult делит бюджет между
  массивами, второй массив урезал бы rows вдвое
- Цена: модели нужна расшифровка формата в описании инструмента (+~0.5 КБ)

## 2026-08-20 — Пагинация tool-результатов вместо многочастной генерации
- Решение: capToolResult в wrapExecute (единая точка на 33 инструмента),
  лимит в байтах из пресета LLM, при обрезке — страница + _truncated/_hint
- Почему: ошибка про размер ВХОДНОГО блока провайдера, а не потолок вывода —
  механика «отчёт в N запросов» её не лечит; жёсткий slice рвёт JSON и модель
  домысливает обрывок
- Затронуто: lib/ai/tool-result-limit.ts, tools.ts, orchestrator, provider,
  tool-executor, system-prompt, LlmSetting + /admin/llm

## 2026-08-19 — LLM-пресеты в БД вместо env, ключи plaintext+маска
- Решение: LlmSetting в БД, активный пресет для всех LLM-вызовов, env — fallback;
  ключи открытым текстом (наружу только маска); openai_compatible через
  createOpenAI().chat() без новой зависимости; «одна активная» — транзакцией
- Почему: смена модели/провайдера без редеплоя (Gonka ~бесплатен); частичный
  unique-индекс Prisma не выражает (drift); .chat() покрывает Chat Completions
- Затронуто: prisma, src/lib/ai/provider.ts, orchestrator, gaps, api/admin/llm*, admin/llm
