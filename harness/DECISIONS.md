## 2026-08-20 — Пагинация tool-результатов вместо многочастной генерации
- Решение: capToolResult в wrapExecute (единая точка на 33 инструмента),
  лимит в байтах из пресета LLM, при обрезке — страница + _truncated/_hint
- Почему: ошибка про размер ВХОДНОГО блока провайдера, а не потолок вывода —
  механика «отчёт в N запросов» её не лечит; жёсткий slice рвёт JSON и модель
  домысливает обрывок
- Затронуто: lib/ai/tool-result-limit.ts, tools.ts, orchestrator, provider,
  tool-executor, system-prompt, LlmSetting + /admin/llm

## 2026-08-19 — LLM-пресеты в БД вместо env, ключи plaintext+маска
- Решение: LlmSetting в БД, активный пресет для всех LLM-вызовов, env — fallback;
  ключи открытым текстом (наружу только маска); openai_compatible через
  createOpenAI().chat() без новой зависимости; «одна активная» — транзакцией
- Почему: смена модели/провайдера без редеплоя (Gonka ~бесплатен); частичный
  unique-индекс Prisma не выражает (drift); .chat() покрывает Chat Completions
- Затронуто: prisma, src/lib/ai/provider.ts, orchestrator, gaps, api/admin/llm*, admin/llm
