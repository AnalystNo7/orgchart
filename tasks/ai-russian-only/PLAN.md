## Альтернативы

- **Вырезать иероглифы в потоковом фильтре**: отвергнута, потому что теряется смысл фразы («Избыточное количество … (примерно…)»), а пользователь не узнаёт, что слово пропало.
- **Кнопка «Переписать по-русски» вместо автопочинки**: отвергнута заказчиком; оставлена как запасной путь, если автоматическая замена текста окажется неуместной (тогда `replace` меняется на пометку + кнопка, серверная часть та же).
- **Снизить температуру**: заказчик решил не трогать; отмечено как самый сильный рычаг против утечек в LIMITATIONS/REPORT.
- **Второй проход на каждый ответ (всегда переписывать)**: отвергнута, потому что удваивает стоимость и время каждого ответа ради редкого дефекта; проверка регэкспом бесплатна.

## Риски

- 🟡 Модель при починке перепишет что-то ещё (числа, формулировки) → следим: промпт починки запрещает менять содержание; сравнение длины и чисел в логе (`[AI_LANG] длина X→Y`); при расхождении чисел >10 % оставить исходный текст.
- 🟡 Починка сама вернёт иероглифы → предусмотрено: проверка результата, исходный текст остаётся, лог «не исправлено».
- 🟡 Задержка: ответ уже виден, затем через 3–10 с текст «моргнёт» заменой → следим: статус `llm_analyzing` с детализацией «Проверяю язык ответа…» на время починки.
- 🟢 Напоминатель в последнем ходе не сохраняется: копия только для модели.
