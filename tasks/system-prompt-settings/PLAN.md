## Шаги

1. `prisma/schema.prisma` — модель `AiPromptSetting` (id, content, updatedAt);
   нет строки = стандартный промпт; миграция.
2. `system-prompt.ts` — `DEFAULT_METHODOLOGY_PROMPT` (с `{{scenario_name}}`),
   `buildTechnicalPrompt()`, `buildSystemPrompt(scenarioName, custom?)`,
   `getSystemPrompt(scenarioName)` с фолбэком по образцу `getLlm()`.
3. `orchestrator.ts` — `await getSystemPrompt(...)`; в `[AI_RUN]` добавить
   «промпт стандартный|изменён».
4. `/api/admin/prompt` — GET (эффективный текст + isCustom + default +
   technical), PUT (upsert, zod 1…50000 симв), DELETE (сброс).
5. `/admin/settings/layout.tsx` — вкладки по паттерну references; проверка
   isAdmin здесь. Перенос `/admin/llm/page.tsx` → `/admin/settings/llm/page.tsx`;
   старый путь — redirect. Новая `/admin/settings/prompt/page.tsx`.
6. `Sidebar.tsx` — пункт «Настройки» → `/admin/settings/llm`.
7. `harness/PROJECT.md` — актуализация двух строк карты.
8. `tsc --noEmit`, `next build`, локальная миграция; прогоны из BRIEF.

## Альтернативы

- **Редактировать весь промпт целиком**: отвергнута, потому что технические
  секции только что настроены под таймауты — их правка из окна молча ломает
  маршрутизацию инструментов, а диагностика такой поломки дороже ограничения
  скоупа. «Технический промт» показывается read-only.
- **Промпт per-пресет (поле в LlmSetting)**: отвергнута, потому что умножает
  сущности без запроса и делает текст промпта зависимым от того, какой пресет
  активен, — легко забыть.
- **Версии с историей и откатом**: отвергнута, потому что отдельная таблица и
  UI ради непрошеной функции; «Сбросить к стандартному» покрывает главный риск.

## Риски

- 🟡 Пользователь удалит `{{scenario_name}}` из текста → следим: не ошибка,
  просто в промпте не будет имени сценария; подстрочник предупреждает.
- 🟡 Таблица не создана до migrate deploy → следим: getSystemPrompt ловит
  ошибку и падает на дефолт с предупреждением в лог (паттерн getLlm).
- 🟡 Слишком длинный текст раздует вход каждого шага → следим: zod-потолок
  50 000 симв.; объём виден в [AI_STEP_START].
- 🟢 Перенос страницы LLM меняет только путь; логика и API не трогаются.
