# PLAN: Пагинация результатов инструментов AI

Дата: 2026-08-20

## Шаги

1. Prisma: `LlmSetting.toolResultMaxBytes Int?` + миграция `20260820000000_add_tool_result_limit`
2. Валидация/DTO/API: поле в `llm-setting.ts` (4000…1000000), `toLlmSettingDto`, create/update роуты
3. UI: поле в `LlmSettingForm.tsx` + `summaryLine` на `/admin/llm`
4. Ядро: `src/lib/ai/tool-result-limit.ts` — `capToolResult(raw, maxBytes)`; байты через `Buffer.byteLength`; массив → страница + `_truncated/shown/total/nextOffset/_hint`; объект → скаляры + урезанные массивы; не-JSON → обрезка по строке; JSON всегда валиден
5. Конвейер: `buildTools(scenarioId, onProgress, maxBytes)` → `capToolResult` в `wrapExecute`; в orchestrator `getLlm()` выше `buildTools`; `toolResultMaxBytes` в `LlmGenerationSettings`
6. Пагинация у тяжёлых: `offset`/`limit` в схемах и хендлерах `get_org_structure` (+ department details, employees, compare)
7. Убрать pretty-print: `JSON.stringify(x, null, 2)` → `JSON.stringify(x)` в tool-executor (49 мест)
8. `system-prompt.ts`: как трактовать `_truncated` (не делать выводов «по всей организации» на неполной выборке)
9. tsc --noEmit, коммит, push

## Альтернативы

- Многочастная генерация (1–8 запросов) как в другом проекте пользователя: отвергнута — лечит потолок ВЫВОДА, а ошибка про размер ВХОДНОГО блока; блок ушёл бы целиком в каждый из N запросов. Вынесена отдельной задачей.
- Жёсткий `slice` до лимита: отвергнут — рвёт JSON посреди структуры, модель домысливает обрывок и выдаёт неверные выводы; цена ошибки выше экономии кода.
- Рефакторинг `executeTool` на возврат объектов вместо строк: отвергнут — 49 хендлеров и вся сигнатура ради того же результата, который даёт одна обёртка.

## Риски

- 🟡 Модель может не заметить `_truncated` и выдать выводы по неполным данным → следим: явный `_hint` в результате + блок в системном промпте
- 🟡 Лимит провайдера может считаться в токенах/символах, а не байтах → следим: считаем байты (строже), при повторе ошибки снижаем лимит в пресете без редеплоя
- 🟢 Sed-замена pretty-print может задеть строку вне tool-executor → проверяем диффом и tsc
