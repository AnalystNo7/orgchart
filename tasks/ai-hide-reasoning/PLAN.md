## Шаги

2. **`src/lib/ai/think-filter.ts` (восстановить из `e10b800` и расширить)** — `createThinkFilter(marker)`:
   - Состояние: `inside` (после `<think>` без закрытия), `tail` (удержанный хвост), `hidden` (накопленный скрытый текст текущего шага), `trimLeading`.
   - `push(delta) → { text, hiddenDelta }`: вне блока — как раньше (`heldPrefix` для `<thinking>`); внутри блока конец по `</think>` **или** по строке-маркеру `^\s*### Ответ\s*$` (регэксп по константе, регистронезависимо, допускаются `#`–`###`). Удержание хвоста: последний фрагмент после `\n`, если он является префиксом маркера (по образцу `heldPrefix`), плюс прежнее удержание для тега. Маркер и ведущие переводы строк после него в текст не попадают.
   - `endStep({ toolCalls: boolean }) → { text, discarded, revealed }`: если `inside` и шаг закончился инструментами — `hidden` отбрасывается (`discarded = K`); если `inside` и шаг финальный — `hidden` возвращается как текст (`revealed = K`, страховка); `tail` доливается; состояние сбрасывается для следующего шага.
   - Экспорт чистый, без React и SDK (проверяется скриптом).

3. **`src/lib/ai/orchestrator.ts`**:
   - `streamText({ …, includeRawChunks: rawChunks > 0 })`; цикл по `result.fullStream` вместо `textStream`:

     - `finish-step` → `thinkFilter.endStep({ toolCalls: part.finishReason === "tool-calls" })`; `revealed` → через `nameFilter` в текст; лог `[AI_REASONING] шаг N: скрыто K символов, граница: маркер | закрывающий тег | инструменты (отброшено) | не найдена (раскрыто)`.
     - `raw` → первые N на шаг в `[AI_RAW]` (JSON, 600 символов).
     - `error`, `abort` → как сейчас через `onError`/`lastStreamError`; `tool-call`/`tool-result` не обрабатывать (остаются в `onStepFinish`).
   - `onStepFinish`, `experimental_onStepStart`, повторы, очередь, отмена — без изменений. Разделитель `\n\n` между шагами (`experimental_onStepStart`) сохраняется.

## Альтернативы

- **Только эвристика границы (первый заголовок/таблица после `<think>`)**: отвергнута как основной механизм, потому что рассуждения MiniMax сами содержат markdown-заголовки и таблицы-черновики; ложное срабатывание прячет начало ответа — ровно то, из-за чего был откат. Остаётся кандидатом во второй триггер после оценки доли прогонов без маркера.
- **Сменить провайдер на `@ai-sdk/openai-compatible` (разбирает `reasoning_content`)**: отвергнута до диагностики, потому что не подтверждено, что Gonka вообще присылает отдельное поле; наблюдаемый факт — `<think>` внутри `content`. Диагностика `[AI_RAW]` входит в план и при положительном результате это станет следующей задачей.
- **Показывать рассуждения свёрнутым блоком и хранить их**: отвергнута заказчиком (скрыть полностью); хранить черновик в БД нет смысла, если его никто не читает, а история модели без него короче.
- **Отключить размышления у модели параметром**: отвергнута, потому что для MiniMax M2 режим interleaved thinking не отключается.

## Риски

- 🟡 MiniMax не ставит маркер → следим: страховка раскрывает текст (как сегодня), лог `[AI_REASONING] … не найдена` считает долю; при высокой доле — эвристика вторым триггером отдельным решением.
- 🟡 Маркер появится внутри рассуждений в начале строки («сейчас напишу ### Ответ») → следим: промпт запрещает; последствия — покажется хвост черновика, ответ не теряется.
- 🟡 Переход с `textStream` на `fullStream` меняет цикл чтения → следим: части `error`/`abort` обрабатывать так же, как сейчас через `onError`/`finishReason`; регресс 45 кейсов покрывает 429/отмену/очередь.
- 🟢 Ведущее `\n\n` между шагами: разделитель добавляется только если `partialText` непуст — при полностью скрытом шаге 1 лишней пустой строки не будет.
- 🟢 `includeRawChunks` включается только при флаге: без него объём стрима прежний.
