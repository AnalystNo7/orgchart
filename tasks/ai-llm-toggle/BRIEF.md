# BRIEF: обращение к модели по кнопке, а не по префиксу `!ai`
Дата: 2026-09-11

## Формулировка своими словами
Чтобы вопрос ушёл в модель, сейчас нужно вручную набрать `!ai ` перед текстом. Это защита от случайной траты токенов (коммит `2b1d828` от 1 апреля: локальный поиск по умолчанию, внешняя модель только по явному согласию), но набирать префикс неудобно, а пользователи о нём не знают. Нужно сохранить смысл защиты (осознанное включение), убрав ручной ввод: тумблер «AI» у поля ввода (по умолчанию выключен, состояние запоминается) и кнопка «Отправить в AI» в ответе-заглушке, когда локальный поиск не справился. Заодно починить два места, которые из-за шлюза не доходят до модели: быстрые действия в чате и «Сравнить» на gap-анализе.

## Контекст
- Сервер: `src/app/api/ai/chat/route.ts:48-90` — `useLlm = content.startsWith("!ai ")`; иначе `processLocalQuery` (интенты по ключевым словам: бенчмарки, отклонения, база знаний); не поймано → текст-заглушка «добавьте префикс `!ai`», `done { local: true }`; с префиксом — префикс срезается и запрос идёт в `runChat`.
- Клиент: `AiChatPanel.tsx:238` `sendMessage(text)`, тело запроса `{ scenarioId, conversationId, messages }` (`:268-272`), поле ввода и кнопка отправки `:574-600`; события `done` клиент не разбирает.
- `QuickActions.tsx:11-15` — пять аналитических промптов без префикса. «Анализ структуры» содержит «бенчмарк», «span of control», «overhead» → интент бенчмарков (локальная таблица вместо анализа); «Найти проблемы» содержит «проблем» → локальная диагностика; остальные три → заглушка. Ни одна кнопка не доходит до модели.
- `src/app/gap-analysis/page.tsx:85-106` — «Сравнить» шлёт свой текст напрямую в `/api/ai/chat` без префикса; текст содержит «проблемы» → локальная диагностика вместо `compare_scenarios`.
- Стор: `ai-store.ts` без persist; образец сохранения настроек в `localStorage` есть в `store.ts:21-29,135-138`. `AiMessage { role, content, toolCalls?, timestamp }`.
- UI-примитив `ui/switch` (Radix) есть в проекте.
- Похожих записей в журналах нет; в `harness/PROJECT.md` шлюз `!ai` описан в строке AI-ассистента (`local-query.ts — ответы без LLM`).

## Критерии успеха
- [ ] У поля ввода тумблер «AI» с подписью; по умолчанию выключен; состояние переживает перезагрузку страницы (localStorage).
- [ ] Тумблер выключен: обычный вопрос идёт в локальный поиск как сейчас; если не пойман — ответ-заглушка без упоминания префикса, под ним кнопка «Отправить в AI», клик отправляет тот же вопрос в модель без повторного ввода.
- [ ] Тумблер включён: любое сообщение сразу идёт в модель; в статусе видно обычную цепочку фаз (не «Локальный поиск»).
- [ ] Быстрые действия (5 кнопок) и «Сравнить» на gap-анализе всегда идут в модель независимо от тумблера: в чате чипы вызовов инструментов, а не таблица бенчмарков и не заглушка.
- [ ] Префикс `!ai ` продолжает работать (обратная совместимость для тех, кто привык).
- [ ] Юнит-тест разбора намерения (флаг / префикс / без всего / срез префикса) зелёный; регресс `retry-test` 54, `queue-unit` 14, `employee-economics` 20, `think-filter` 23, `think-split` 9; `tsc` без новых ошибок; `next build`.
