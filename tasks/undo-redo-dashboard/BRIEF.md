# BRIEF: Undo/redo на дашборде — «нажимается, но ничего не меняется»
Дата: 2026-09-08

## Формулировка своими словами
Кнопки «Отменить/Повторить» в панели инструментов дашборда активны, клик
проходит, но схема не меняется. Наблюдается локально и на VPS. Перед этим
заказчик выделял и создавал/удалял блоки на дашборде. Нужно найти причину
с доказательством (воспроизведение), починить и дать пользователю понятную
обратную связь: что именно отменено или почему отмена не удалась.

## Контекст
- Замысел: каждое изменение через REST пишет `ActionLog` (18 типов в
  `src/lib/action-logger.ts`); `/api/actions` отдаёт `canUndo/canRedo`;
  стор `undo()` → `POST /api/actions/undo` → `triggerRefresh`.
- По коду найдены три дефекта-кандидата:
  1. `OrgChart.tsx` после своих действий (создание 416, удаление 393,
     родитель 642, импорт 604) не зовёт `fetchUndoRedoState()` — кнопки
     не обновляются (образец правильного вызова — строка 298).
  2. Ошибки отмены глотаются: `action-logger.ts:44-47` (`.catch(() => {})`
     при удалении созданного блока) и `store.ts:262-268` (`!res.ok` → молча
     `false`).
  3. Стек отмены общий на сценарий: правки в справочниках (10 типов)
     откатываются кнопкой на дашборде, где их не видно; API возвращает
     `actionType`, стор его выбрасывает.
- Не логируются вовсе: AI-инструменты, импорт Excel, клонирование — вне
  объёма (решение заказчика).
- Образец видимой ошибки без toast-библиотеки — `BulkActionsBar`.

## Критерии успеха
- [ ] Таблица воспроизведения A–E (см. PLAN) с ответами сервера и
      состоянием `ActionLog` — до починки.
- [ ] После починки: создание/удаление блока с дашборда отменяется и
      повторяется, схема меняется; кнопка активна сразу после действия,
      без перезагрузки.
- [ ] Отмена, которую нельзя выполнить (у блока появились дети/сотрудники),
      не помечается выполненной и показывает причину рядом с кнопками.
- [ ] Отмена действия из справочника показывает «Отменено: …» с русской
      меткой типа действия.
- [ ] `tsc` — 14 pre-existing, lint — 51 pre-existing; цвета/разметка
      блоков ШЕТИЛ не тронуты.
