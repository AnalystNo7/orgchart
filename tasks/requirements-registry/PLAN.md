# PLAN: реестр требований

Дата: 2026-08-22

## Шаги
1. Шаблон → harness/templates/REQUIREMENTS.md (1-в-1, diff-проверка).
2. harness/REQUIREMENTS.md из шаблона: ~33 карточки (3 BR, 8 UR, 13 FR,
   3 NFR, 4 RULE, 5 CON) по инвентарю из плана; служебные разделы; матрица.
3. PROJECT.md — упомянуть REQUIREMENTS.md в структуре harness/.
4. Самопроверка: поля карточек, статусы/проверки, сквозные ID, сходимость
   матрицы, цепочки «Реализует» до BR.

## Альтернативы
- **Адаптировать шаблон при копировании**: отвергнута — шаблон переносим
  между проектами, специфика живёт в рабочем экземпляре.
- **Проставить MoSCoW самому**: отвергнута — приоритет ставит заказчик,
  аналитик только предлагает в комментарии.
- **Извлекать из кода без документальных следов**: отвергнута — запрет
  шаблона «не придумывать».

## Риски
- 🟡 Ретроспективные формулировки могут исказить намерение заказчика →
  следим: каждая карточка с точным источником; сомнения — в открытые вопросы.
- 🟢 Реестр не влияет на код — только документы.

## Бюджет
- Файлов: 3 новых + 1 правка + 2 документа задачи / Время: ~1.5 ч
