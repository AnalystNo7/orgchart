# BRIEF: Оформление markdown в ответах AI + «Ход рассуждений» вместо сырых `<think>`
Дата: 2026-09-08

## Формулировка своими словами
В ответах ассистента две проблемы, обе видны на присланном примере с таблицами:
1. Markdown размечен классами `prose`, но плагин `@tailwindcss/typography`
   в проекте не установлен — таблицы без границ, списки без номеров. В узкой
   колонке это не бросалось в глаза, в развёрнутом окне — бросается.
2. DeepSeek-совместимые шлюзы отдают размышления в тексте между
   `<think>…</think>`; фильтра нет, размышления видны как часть ответа и
   уходят в базу вместе с ним.

Нужно: (а) подключить typography и подогнать таблицы/списки/заголовки под
токены проекта; (б) вырезать `<think>` на сервере в потоке и показывать
русскоязычным свёрнутым блоком «Ход рассуждений модели», во время генерации —
статус «Модель рассуждает…».

## Контекст
- Поток: `orchestrator.runChat` → `result.textStream` → `createToolNameFilter`
  (push/flush) → `onText` → SSE `text` → `appendToLastAssistant`; `onDone`
  сохраняет `messages` (Json) в `AiConversation`.
- Единственный `ReactMarkdown` в проекте — `ChatMessage.tsx`.
- Клиент при новом запросе шлёт историю как `{role, content}`; сервер сохраняет
  её же плюс новый ответ. Значит любое доп. поле ответа теряется на следующем
  ходу, если клиент его не передаёт (так уже происходит с `toolCalls`).
- Старые беседы уже содержат `<think>` в `content`.

## Критерии успеха
- [ ] В собранном CSS есть правила `.prose`; таблица в ответе — с границами,
      серой шапкой uppercase, табличными цифрами; нумерованный список — с номерами.
- [ ] Ни в `text`-событиях SSE, ни в `content` сохранённого сообщения нет
      `<think>`; содержимое блока приходит событием `reasoning` и сохраняется
      в поле `reasoning` сообщения ассистента.
- [ ] Тег, разрезанный границей дельт (`<thi`+`nk>`), не утекает; обычный
      текст с `<b>` / `1 < 2` проходит без изменений; незакрытый блок целиком
      уходит в рассуждения.
- [ ] В UI: свёрнутая строка «▸ Ход рассуждений модели», по клику раскрывается;
      по умолчанию свёрнута; во время рассуждений статус «Модель рассуждает…».
- [ ] Старые беседы с `<think>` в `content` открываются чисто (разбор при отрисовке).
- [ ] Поле `reasoning` прошлых ответов переживает следующий ход беседы.
- [ ] `tsc` — 14 pre-existing, lint — 51 pre-existing.

## Открытые вопросы
- Как показывать размышления? — свёрнутый блок «Ход рассуждений» (ответ заказчика).
- Стиль таблиц — под токены проекта (ответ заказчика).
- Где резать — на сервере, в потоке (ответ заказчика).
- Слать ли reasoning прошлых ответов модели в контекст? — нет: в LLM уходят
  только `role/content`, поле хранится ради истории.
