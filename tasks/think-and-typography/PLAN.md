8. `harness/PROJECT.md` — стек и строка про AI-ассистента.

## Альтернативы

- Резать `<think>` на клиенте при отрисовке (как маркеры источников):
  отвергнута, потому что размышления всё равно уходят в базу и в контекст
  следующего запроса, раздувая его; серверный фильтр устраняет причину.
- Использовать `reasoning`-поток AI SDK (`result.reasoningStream` /
  `providerOptions`): отвергнута, потому что не устраняет причину — шлюзы,
  которые кладут `<think>` в текст, через него ничего не отдают; фильтр
  текста нужен в любом случае.
- Собственные CSS-правила для таблиц/списков без typography: отвергнута,
  потому что дольше и хуже покрытие (blockquote, вложенные списки, код);
  плагин даёт базу, поверх — токены.

## Риски

- 🟡 Ответ начинается с `<` (HTML-фрагмент) → следим: удерживается только
  хвост, совпадающий с началом тега, не длиннее `</thinking>`; кейс `<b>` в
  тестовом скрипте.
- 🟡 `display:block` у `<table>` для горизонтальной прокрутки может сломать
  раскладку колонок → следим: визуальная проверка таблицы 8×8 в браузере.
- 🟢 Typography-плагин действует только внутри `.prose`; вне чата `.prose`
  не используется.
