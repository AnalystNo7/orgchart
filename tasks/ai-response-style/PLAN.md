## Альтернативы
- **Только промпт**: отвергнута — DeepSeek в длинных прогонах соблюдает
  инструкции нестабильно; фильтр гарантирует кодом.
- **Только фильтр**: отвергнута — имена заменятся, но фразы вокруг механики
  вызовов останутся; против них работает только промпт.
- **Сворачивание размышлений в UI**: отложена пользователем.

## Риски
- 🟡 Удержание хвоста задержит вывод, если модель пишет длинное слово →
  следим: кап 40 симв (максимум имени — 22), дольше не держим.
- 🟡 Замена заденет легальный код в ответе (модель цитирует API нарочно) →
  следим: замена по границам слов; кейс редкий, метка в «» остаётся понятной.
- 🟢 Реэкспорт сохраняет клиентские импорты без правок.
