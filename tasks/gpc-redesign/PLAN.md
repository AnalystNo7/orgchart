## Альтернативы
- Скопировать CSS образца целиком (tokens/shell/components/pages.css) и вешать
  классы `.btn`, `.card`, `.tbl` в разметке: отвергнута, потому что рядом с Tailwind 4
  и shadcn это вторая параллельная система стилей — конфликты специфичности, двойные
  правила на одном элементе и обязательная переразметка всех 21 страницы вместо
  правки cva-вариантов в 18 файлах.
- Перейти на Ant Design 5, как рекомендует README образца: отвергнута, потому что это
  замена всей UI-библиотеки в работающем проекте (18 примитивов, формы, таблицы,
  диалоги, xyflow-канвасы) — недели работы и полный регресс UI ради того же результата.
- Только перекрасить акценты, не трогая шрифты и каркас: отвергнута, потому что узкие
  заголовки и синий сайдбар — половина узнаваемости образца; без них «тот же стиль»
  не читается, а работа по перекраске всё равно будет проделана.

## Риски
- 🔴 Сломать цвета ШЕТИЛ на дашборде → ДО начала: зафиксировать, что блок
  `--color-shetil-*` в globals.css и `SHETIL_CONFIG` не редактируются;
  после правок сверить `git diff` по этим местам — должен быть пустым.
- 🟡 Кириллица в PT Sans Narrow/Inter → следим: next/font `subsets: ['latin','cyrillic']`,
  визуальная проверка русского текста в заголовках.
- 🟡 Скачивание шрифтов на этапе сборки требует сети (next/font тянет файлы из Google
  при build) → следим: если прокси не пускает, кладём woff2 локально в `public/fonts`
  и подключаем через `next/font/local`.
- 🟡 Глобальная смена высоты кнопок/инпутов может разъехать плотные тулбары
  → следим: проверяю страницы с самыми плотными панелями (/finance, /processes).
- 🟢 Тестов нет — регресс ловится только глазами и скриншотами.
