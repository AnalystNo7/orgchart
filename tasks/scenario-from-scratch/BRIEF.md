# BRIEF: сценарий с нуля + первый блок на пустом дашборде
Дата: 2026-08-26

## Формулировка своими словами
Сейчас сценарий можно создать только клонированием существующего: в диалоге
«Создать сценарий» поле «На основе» обязательно, кнопка заблокирована без него.
Нужно дать путь «с нуля»: пустой сценарий без родителя, и чтобы в нём на
дашборде можно было начать строить структуру — создать первый (корневой) блок,
которого сейчас никак не создать: кнопки «+» живут на узлах, а узлов нет.

## Контекст
- `POST /api/scenarios` уже создаёт пустой сценарий (name/description, без
  createdFromId) — эндпоинт готов, им никто не пользуется.
- `POST /api/departments` принимает `parentId: null` — корневой блок создаваем
  существующим API.
- Весь инструментарий создания блоков на дашборде есть: `AddDepartmentDialog`,
  `handleAddDepartment` в `OrgChart.tsx`, «+» на узлах, контекстное меню.
  Не хватает только точки входа при `departments.length === 0`.
- Импорт оргструктуры+сотрудников (`ExcelImport`) — самостоятельный диалог
  с props `open/scenarioId`, живёт на `/references/employees`; переиспользуем
  на пустом дашборде.
- Решения заказчика: «с нуля» — пунктом в селекте «На основе»; пустой экран
  дашборда предлагает и создание корневого блока, и импорт Excel; корень
  один (как сейчас) — после первого блока заглушка исчезает.

## Критерии успеха
- [ ] В диалоге создания сценария можно выбрать «— Пустой сценарий —»
      (первый пункт селекта) и создать сценарий без родителя
- [ ] У пустого сценария в списке колонка «На основе» показывает «—»
- [ ] На дашборде пустого сценария — заглушка с кнопками «Создать корневое
      подразделение» (открывает существующий AddDepartmentDialog, создаёт блок
      с parentId=null) и «Импортировать из Excel» (открывает ExcelImport)
- [ ] После создания первого блока заглушка исчезает, дальше работают
      существующие «+» на узлах
- [ ] Клонирование «На основе» работает как раньше
- [ ] tsc: не больше 14 pre-existing ошибок; lint: не больше 51 замечания

## Открытые вопросы
- Несколько корней — отклонено заказчиком (оставляем один, UI как сейчас).
- Undo создания корня через ActionLog — не трогаем: создание блоков уже
  логируется существующим API-путём, ничего нового не добавляем.
