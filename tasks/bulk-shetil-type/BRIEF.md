# BRIEF: мультивыделение блоков и массовая смена типа ШЕТИЛ
Дата: 2026-08-26

## Формулировка своими словами
После массовой загрузки из Excel типы подразделений приходится править по
одному через панель подразделения. Нужно: выделить несколько блоков прямо на
канвасе (Ctrl/Cmd+клик, рамка по Shift) и назначить всем выбранным тип одним
действием. «Перекрашивание» = смена shetilType; сами цвета типов стандартные
и не меняются.

## Контекст
- ReactFlow 12 поддерживает мультивыделение из коробки (multiSelectionKeyCode,
  selectionKeyCode, флаг selected на узле, onSelectionChange) — в OrgChart.tsx
  просто не включено.
- PATCH /api/departments/[id] умеет менять тип по одному с логом undo;
  массового эндпоинта нет — N одиночных PATCH дали бы N нажатий Ctrl+Z.
- actionType в ActionLog — String: новый тип действия без миграции.
- Решения заказчика: Ctrl+клик + рамка по Shift; панель действий — только
  смена типа (расширяемая); тип меняется ровно у выделенных, без каскада.

## Критерии успеха
- [ ] Ctrl/Cmd+клик собирает выделение; Shift+протяжка — рамка; обычная
      протяжка панорамирует, обычный клик открывает панель, как раньше
- [ ] Выделенные блоки подсвечены кольцом; цвета заливки ШЕТИЛ не изменены
- [ ] При ≥2 выделенных внизу канваса панель: «Выбрано: N» + 4 типа + сброс
- [ ] Клик по типу меняет shetilType всем выделенным одним запросом
- [ ] Ctrl+Z откатывает всю пачку разом (включая разные исходные типы),
      Ctrl+Shift+Z повторяет
- [ ] tsc ≤ 14 pre-existing ошибок; lint ≤ 51 замечания

## Открытые вопросы
- Массовое удаление и смена родителя — отклонены заказчиком (только смена типа).
- Каскад на детей — отклонён заказчиком.
